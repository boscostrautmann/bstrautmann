# Portfolio V2 — Bosco Strautmann

Version 2.0 de mon site web personnel et portfolio professionnel. Ce projet met en avant mes compétences techniques, mes réalisations web et mon parcours dans le domaine de l'IT.

🚀 **Démo en ligne :** [bstrautmann.com](https://bstrautmann.com)

---

## 🛠️ Stack Technique

* **Style :** Tailwind CSS
* **Scripting :** JavaScript Vanilla (ES6+)
* **Features :** Support Progressive Web App (PWA) & Web Clip iOS, mode sombre natif
* **Hébergement & Serveur :** Configuration Apache (`.htaccess`) pour la gestion du cache et des redirections HTTPS

---

## 💡 Fonctionnalités Majeures

* **Design Responsive & Léger :** Interface optimisée pour mobile, tablette et desktop sans dépendances lourdes.
* **Expérience PWA :** Installable sur smartphone avec prise en charge du mode plein écran (*standalone*).
* **Mode Sombre / Clair :** Adapté automatiquement aux préférences du système utilisateur.
* **CV Intégré :** Téléchargement direct au format PDF.
